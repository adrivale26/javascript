About Me

My name is Adriana Valencia and I am a student at Dallas College working towards an associates's degree in Web Development. My interest for web design began in highschool when I took an HTML class. From that day forward, I've enjoyed designing and creating websites it has allowed me to express myself, challenged me, and showcased what I learned throughout my time in college. After graduating, my goal is to find a job as a web designer or in a similar field. My hobbies include baking, cooking, cleaning, and working out.

Before this course, I didn't fully understand what JavaScript was. Throughout each assignment, I began to gain a deeper understanding of JavaScript and how to use it to create interactive web pages. I learned how to munipulate the Document Object Model, use the JQuery library, arrays, for loops, and functions and apply them to several webpages. I've only ever used Notepad ++ and TextMate as my text editors, so when I started using Visual Studio Code, I realized how helpful it was. VS Code pointed out errors and added suggestions to make coding easier. I also learned how to use GitHub to upload my assignments and create a portfolio. Overall, this course has helped me become more confident in using JavaScript, Visual Studio Code, and Github. I am able to use these skills for assignments and future jobs.
