About Me

My name is Adriana Valencia and I am a student at Dallas College working towards an associates's degree in Web Development. My interest for web design began in highschool when I took an HTML class. From that day forward, I've enjoyed designing and creating websites as allows me to express myself, challenges me, and showcases what I learned throughout my time in college. After graduating, my goal is to find a job as a web designer or in a similar field. During my free time, I like to do therapeutic activities such as baking, cooking, cleaning, and working out.

Throughout this course, I learned how to incorportate Jquery effects, events, for loops, arrays, functions, and methods into several HTML pages. I leanred how to upload web pages from Visual Studio code into my GitHub Repositiory. I gained a strong understanding of how JavaScript works and how I can use it to create an interactive webpages. Overall, this course has helped me become more confident in using JavaScript, Visual Studio Code, and Github, allowing me to use these skills for future jobs.
